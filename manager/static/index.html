    快捷操作

    截图

    向模拟器输入文字

    先在画面中点一下输入框。纯英文数字走 adb input；含中文时走 uiautomator2 输入法。

    首次使用

    1. 先在「设备与微信」页选择机型：手机（小号专用，会挤掉其他手机上的登录）或 平板（Pad 模式，可与你的真手机同时在线）。
    2. 安装微信（上传官方 APK 或填写下载地址）。
    3. 在右侧画面中打开微信登录。平板模式会显示二维码，用真手机扫码确认。
    4. 登录后去「数据库验证」页跑解密验证。

    设备配置

    手机模式会挤掉同账号在其他手机上的登录；平板模式可与真手机同时在线。只影响账号登录方式，不影响后续读取和转发。
    留空则使用机型默认值。平板需保证 宽÷(dpi÷160) ≥ 600。
    修改后需重启模拟器生效；已登录的微信数据不会丢失。

    上传 APK

    或从地址下载

    微信只有 arm64 版本，要靠系统镜像自带的 ARM 指令转译运行（API ≥ 30 的 x86_64 镜像）。安装后看「ABI」一栏是否为 arm64-v8a，并观察运行是否稳定。

    看门狗

    解密验证

    读取 uin → 定位 EnMicroMsg.db → 复制到容器 → 依次尝试 md5(IMEI+uin)[:7] 密钥 → 统计。微信登录后运行。

    实时监听

    每 2 秒检查数据库与 WAL 是否变化，有变化就拷贝并读取新消息。请用别的微信号给它发几条消息，看「延迟」列：从消息时间到这里读到的秒数。

    会话列表

    点击会话 ID 可以填入「发送验证」页。

    界面自动化发送

    用 am start LauncherUI --es Chat_User 打开会话，再通过 uiautomator2 填入文字并点「发送」。建议先发给「文件传输助手」（filehelper）。

    送到模拟器

    方式一：相册识别（推荐）

    把图片推送到模拟器相册，然后打开微信「扫一扫」并尝试自动点「相册」，最后在画面里选中最新那张。

    方式二：虚拟摄像头

    用于微信不允许从相册识别的码（比如登录确认）。会把图片贴到模拟器虚拟场景的墙上，并把摄像头切到 virtualscene。需要重启模拟器，然后在扫一扫里转动视角（按住 Alt + 鼠标 / WASD）对准墙上的图片。
